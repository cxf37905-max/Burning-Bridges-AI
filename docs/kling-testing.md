# 当前生成流程与人工验收

网站仅使用Kling O3 Edit单次15秒流程。代理不得自行调用模型API，也不运行付费生成脚本。旧双段脚本、预览页、接缝算法与素材已移除。

1. 服务端验证本人Session、输入和请求身份。
2. 准备照片、私有R2的完整15秒参考片和本地FFmpeg依赖。
3. 数据库事务扣100积分、写唯一消费流水并创建任务。每次实际提交再校验消费流水、租约和未退积分。
4. 单次提交Kling O3 Edit。主体使用elements[0].frontal_image_url，提示词仅为`Replace the main character in @Video1 with @Element1.`。
5. 查询或经验签、绑定令牌及主动查单确认的回调更新状态。
6. 成功后本地加入对应15秒音轨，存私有R2，提供本人鉴权下载。

API明确终态失败退100积分一次，不退款、不重新生成。普通超时或未知提交不退积分、不重发；等待原任务查询或回调。只有明确HTTP发送前DNS/连接失败，允许最多额外2次重连，全部确认未发送才退积分。下载、音轨处理和保存失败只重做本地步骤。

任务调度每分钟，使用CRON_SECRET鉴权。照片签名有效24小时，成片访问期限14天；外部定时媒体删除已移除，生产R2桶须配置原生生命周期：studio-inputs/满1天到期删除，studio-results/满15天到期删除，异步删除可能延后。付费效果和目标部署平台上的FFmpeg、调度、文件生命周期需由用户另行人工验收；接口符合文档不保证画面效果。
